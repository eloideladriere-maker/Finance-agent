# Finance Agent

Assistant financier IA avec analyse de portfolio personnalisée.

## Fonctionnalités
- Import portfolio Excel (.xlsx, .xls, .csv)
- Analyse d'image de portfolio (screenshot, photo)
- Chat IA avec contexte financier personnalisé
- Sessions nommées

## Déploiement

Ce projet tourne entièrement dans le navigateur — aucun serveur requis.

### Clé API
Entrez votre clé API Anthropic directement dans l'interface au démarrage.  
Obtenez une clé sur [console.anthropic.com](https://console.anthropic.com).

> ⚠️ Ne commitez jamais votre clé API dans le code si le dépôt est public.

## Stack
HTML · CSS · JavaScript vanilla · XLSX.js · API Anthropic Claude
